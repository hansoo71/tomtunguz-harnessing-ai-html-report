# 인공지능 이후의 소프트웨어: 하네스 전략 한국어 분석 보고서

토마스 퉁구즈의 글을 바탕으로 작성한 한국어 HTML 분석 보고서입니다. 원문을 그대로 옮기기보다, 기업형 에이전트 운영 모델 관점에서 핵심 명제와 실행 과제를 재구성했습니다.

- 원문: https://tomtunguz.com/harnessing-ai/
- 산출물: 한국어 HTML 보고서, 공개 페이지 배포본, 작업용 저장소
- 작성 시각: 2026년 6월 2일 한국시간

## 실행 방법

```bash
python3 -m http.server 8765
```

브라우저에서 아래 주소를 엽니다.

- `http://127.0.0.1:8765/`
- `http://127.0.0.1:8765/src/`
- `http://127.0.0.1:8765/docs/`

## 한국어 재작성 기준

사용자에게 보이는 본문, 내비게이션, 카드, 구조도, 접근성 라벨, 설명 문구를 한국어 중심으로 재작성했습니다. 원문 영어 제목과 원문 영어 다이어그램은 공개 페이지에서 노출하지 않고, 한국어 인라인 구조도로 대체했습니다.
