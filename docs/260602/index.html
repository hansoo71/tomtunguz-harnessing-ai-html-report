인공지능 이후의 소프트웨어는 하네스를 중심으로 재편됩니다

토마스 퉁구즈의 글을 바탕으로, 대규모 언어 모델을 기업 업무 시스템 안에서 안전하게 실행시키는 하네스 계층을 정리했습니다. 핵심은 더 강한 모델을 고르는 일이 아니라, 모델을 업무·도구·권한·평가 체계 안에 묶어 운영하는 능력입니다.

요약하면, 모두가 비슷한 인공지능 모델을 쓰는 시대에는 모델 자체보다 모델을 업무에 태우는 하네스가 차별화의 중심이 됩니다.

왜 하네스가 중요한가

원시 모델은 지식과 추론 능력을 제공하지만, 기업 업무는 그 자체로 끝나지 않습니다. 실제 업무에는 고객 맥락, 내부 문서, 승인 절차, 도구 호출, 권한 경계, 실패 복구, 감사 기록, 비용 통제가 함께 필요합니다.

따라서 기업 소프트웨어의 경쟁력은 화면과 기능 목록에서, 모델을 둘러싼 실행 구조로 이동합니다. 이 실행 구조가 바로 하네스입니다.

한 문장 결론

하네스는 범용 지능을 기업 업무 수행자로 바꾸는 운영 장치입니다.

이 문서는 원문을 그대로 번역한 것이 아니라, 기업 도입 관점에서 재구성한 한국어 분석본입니다.

하네스 계층 구조도

아래 구조도는 원문의 일곱 구성요소를 한국어 업무 운영 관점으로 다시 그린 것입니다.

일곱 하네스 계층

각 계층은 독립 기능이 아니라 함께 묶여야 하는 운영 체계입니다. 하나라도 약하면 에이전트는 데모 수준을 벗어나기 어렵습니다.

컨텍스트와 메모리

업무 문서, 고객 맥락, 과거 수행 기록, 장기 기억을 모델이 꺼내 쓸 수 있게 정리하는 계층입니다.

도구와 실행

사내 시스템, 문서 저장소, 업무 도구를 안전하게 호출하고 결과를 검증하는 연결 계층입니다.

계획과 반복

목표를 작은 작업으로 나누고, 실행 결과를 관찰하며, 재시도와 중단 조건을 관리하는 제어 계층입니다.

상태와 지속성

긴 작업을 중간에 저장하고, 장애 후 다시 이어서 수행할 수 있도록 세션과 산출물을 보존합니다.

격리 실행환경

파일, 네트워크, 권한, 자격 증명을 분리해 모델 실행이 보안 경계를 넘지 않도록 만듭니다.

관측성과 거버넌스

도구 호출, 판단 근거, 실패 지점, 승인 내역, 품질 평가를 기록해 운영 가능한 시스템으로 만듭니다.

비용과 흐름 최적화

쉬운 단계와 어려운 단계를 나누고, 자동화 범위와 사람 개입 지점을 조정해 품질과 비용을 함께 관리합니다.

경쟁력은 어디로 이동하는가

기존 소프트웨어의 강점

  • 정해진 화면과 업무 흐름
  • 기능 수와 설정 옵션
  • 데이터 입력과 승인 절차
  • 고객별 화면 맞춤 설정

인공지능 이후의 강점

  • 업무별 컨텍스트와 기억 구조
  • 안전한 도구 호출과 권한 경계
  • 실행 추적과 회귀 평가
  • 비용을 고려한 작업 흐름 설계

기업 관점 시사점

하네스는 보조 기능이 아니라 운영 기반입니다

프롬프트 작성이나 단일 챗봇 도입만으로는 기업 업무 전환이 어렵습니다. 실제 차별화는 지식, 도구, 실행환경, 관측성, 비용 통제가 결합된 운영 기반에서 발생합니다.

실증 성공 기준을 다시 잡아야 합니다

한 번 성공한 시연보다 실패 복구, 승인 절차, 로그 추적, 품질 평가, 비용 설명 가능성이 더 중요합니다. 이 기준이 없으면 운영 전환 단계에서 병목이 생깁니다.

도구 연결은 거버넌스 문제입니다

외부 도구를 많이 붙이는 것보다 누가, 언제, 어떤 권한으로, 어떤 근거에 따라 호출했는지를 남기는 설계가 중요합니다.

비용 최적화는 설계 단계에서 결정됩니다

모든 단계를 가장 비싼 모델에 맡기면 확장성이 떨어집니다. 단순 작업, 고위험 판단, 사람 승인 단계를 나눠 비용과 품질을 함께 설계해야 합니다.

실행 과제

1

우선 자동화할 업무를 고르고, 필요한 문서·데이터·승인 기준을 목록화합니다.

2

도구 호출 목록과 권한 경계를 정의하고, 고위험 작업에는 사람 승인 지점을 둡니다.

3

실행 로그, 실패 사례, 품질 평가 기준을 남겨 운영 개선 루프를 만듭니다.

4

비용이 큰 단계와 자동화 효과가 큰 단계를 분리해 단계별 적용 전략을 세웁니다.

제안서용 메시지

기업형 에이전트의 성패는 모델 선택이 아니라, 모델을 안전하고 추적 가능하며 비용 효율적인 업무 수행자로 만드는 하네스 설계에 달려 있습니다.
